# PySide6 UI Test

This folder contains a simple PySide6 UI stub for testing a potential new interface.

## Run

1. Install PySide6:

```bash
pip install PySide6
```

2. Run the test UI:

```bash
python test_pyside6_ui.py
```

## Notes

- This is only a UI prototype for layout testing.
- It does not perform actual download or conversion.
- You can use it as a starting point for a full PySide6 UI integration.
